# Guia de IA Consciente

Página web educativa da atividade de extensão "Desmistificando a Inteligência Artificial: Uso Consciente e Seguro na Sociedade Digital" (Engenharia de Software).

Conteúdo: o que é IA, como ela monta uma resposta, onde aparece no dia a dia, riscos e golpes, checklist de proteção, direitos pela LGPD e o quiz "Golpe ou não?".

## Tecnologias

- HTML, CSS e JavaScript puros, sem bibliotecas
- Fontes Atkinson Hyperlegible e Lexend (pensadas para leitura fácil)
- Acessibilidade: botão para aumentar o texto, alto contraste, tema claro e escuro automático, navegação por teclado, layout para celular

## Arquivos

- `index.html`: estrutura e conteúdo da página
- `style.css`: visual, cores, tamanho de texto e layout responsivo
- `script.js`: tamanho do texto, checklist e lógica do quiz

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub (por exemplo, `guia-ia-consciente`).
2. Envie os arquivos `index.html`, `style.css`, `script.js` e este `README.md` (botão "Add file" > "Upload files").
3. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)` e salve.
4. Em alguns minutos a página fica disponível em `https://SEU-USUARIO.github.io/guia-ia-consciente/`.
5. Gere um QR Code desse endereço para usar na oficina.
